# HyperStructures 2026 Website

This repository contains the GitHub Pages website for HyperStructures 2026: Continuum-Kinetic Models in Hypersonic Transitional Flows.

## Local preview

Open `index.html` directly in a browser, or serve the folder locally using:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Deployment

The site is intended to be deployed using GitHub Pages from the `main` branch and root directory.
